# Image Gallery Viewer

Нативный Windows-просмотрщик галерей изображений для папочной структуры с директориями `img`.

Приложение написано на WPF и собирается в один `.exe` без NuGet-зависимостей. При запуске оно сканирует папку рядом с исполняемым файлом, находит доступные директории `img`, показывает окно выбора галереи и открывает изображения вертикальной лентой на всю ширину окна.

## Возможности

- Нативное Windows-приложение, без браузера, HTML и webview.
- Автоматический поиск галерей по папкам с именем `img`.
- Исключение папки `Downloads` из сканирования.
- Выбор галереи одним кликом.
- Вертикальная лента изображений на всю ширину окна.
- Клавиатурная прокрутка и навигация.
- Полноэкранный режим с учетом нескольких мониторов.
- Перемешивание через `R` с сохранением блоков `name_N` и `name_N_N`.
- Кнопка `?` в окне выбора папки с короткой инструкцией.
- Прогресс-бар подготовки галереи.
- Очистка памяти при закрытии галереи и возврате к окну выбора.

## Структура папок

Каждая галерея должна содержать папку `img`, внутри которой лежат изображения:

```text
CollectionRoot/
  Some Gallery/
    img/
      001.jpg
      002.jpg
      003.jpg
```

Исполняемый файл сканирует директорию, в которой находится сам. В локальном рабочем сценарии production-файл `ImageGalleryViewer.exe` лежит в корне коллекции, а исходники находятся в папке `ImageGalleryViewer`.

## Поддерживаемые форматы

Сканер принимает файлы с расширениями:

```text
.jpg .jpeg .png .bmp .gif .tif .tiff .webp
```

Фактическое декодирование зависит от кодеков, доступных WPF на конкретной Windows-системе.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Up` | Прокрутка вверх |
| `Down` | Прокрутка вниз |
| `Space` | Перейти к следующему изображению |
| `R` | Перемешать порядок, сохраняя номерные блоки |
| `N` | Перейти к следующему номерному блоку |
| `B` | Перейти к предыдущему номерному блоку |
| `F11` | Включить или выключить полный экран |
| `Esc` | Выйти из полного экрана |

## Режимы памяти

Текущая production-версия: `0.3.2`.

Для галерей с `700` изображениями или меньше используется RAM-only режим: изображения декодируются до открытия галереи и удерживаются в памяти, пока галерея открыта. При закрытии галереи WPF-ссылки на изображения явно очищаются, после чего запускается полная сборка мусора.

Для галерей с количеством изображений больше `700` используется скрытый временный lossless BMP-кеш и виртуализированная подгрузка:

- рядом с выбранной галереей создается скрытая папка `.ImageGalleryViewerCache`;
- подготовленные BMP-файлы временно сохраняются в этой папке;
- в RAM остаются только видимые изображения и небольшой буфер рядом с текущим экраном;
- дальние изображения выгружаются из WPF/RAM и при необходимости заново читаются с SSD-кеша;
- временный кеш удаляется при закрытии галереи.

Если приложение аварийно завершилось, оставшуюся папку `.ImageGalleryViewerCache` можно безопасно удалить вручную.

## Сборка

Проект намеренно простой: один C#-файл и стандартные сборки .NET Framework/WPF.

Требования:

- Windows;
- .NET Framework с `csc.exe`;
- WPF-сборки из .NET Framework.

Production-сборка из папки проекта:

```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
  /target:winexe `
  /out:"..\ImageGalleryViewer.exe" `
  /reference:System.dll `
  /reference:System.Core.dll `
  /reference:System.Drawing.dll `
  /reference:System.Windows.Forms.dll `
  /reference:System.Xaml.dll `
  /reference:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\WindowsBase.dll" `
  /reference:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\PresentationCore.dll" `
  /reference:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\PresentationFramework.dll" `
  "Program.cs"
```

Beta-сборки должны называться по шаблону:

```text
ImageGalleryViewer_beta_vX.Y.Z.exe
```

В локальном workflow beta-файлы сохраняются в папку проекта `ImageGalleryViewer`, а production-файл собирается в корень коллекции как `ImageGalleryViewer.exe`.

## Версионирование

Метаданные версии находятся в `AppVersion` внутри `Program.cs`.

При создании beta:

- выставить `Channel = "beta"`;
- увеличить `Version`;
- выставить `ExeName = "ImageGalleryViewer_beta_vX.Y.Z.exe"`;
- добавить `beta vX.Y.Z` в `WindowTitle`;
- добавить запись в `VERSIONS.md`.

При переносе beta в production:

- выставить `Channel = "production"`;
- оставить номер версии promoted-сборки;
- выставить `ExeName = "ImageGalleryViewer.exe"`;
- убрать `beta` из `WindowTitle`;
- собрать production exe в корень коллекции.
